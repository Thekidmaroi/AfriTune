# Licensing and third-party materials

**Decision pending:** No AfriTune repository license has been approved or added.

The repository is public, but that does not by itself authorize reuse, modification, or redistribution. The rights holder should select and publish a suitable license for original code and documentation. The choice must not be assumed on behalf of contributors.

Third-party materials have separate conditions:

- **Fon dataset:** MasakhaNER 2.0 / upstream Masakhane repository. Verify dataset terms, attribution requirements, and redistribution permissions at source.
- **Base model:** `FacebookAI/xlm-roberta-base`. Verify the model's current published license and distribution conditions.
- **Libraries:** Transformers, PyTorch, Datasets, and other packages each retain their own licenses.
- **Experimental outputs:** Check rights and privacy implications before sharing weights, predictions, or examples.

## Before a release

1. Confirm ownership and contributor permissions for original AfriTune materials.
2. Choose and add a recognized license file, with correct copyright attribution.
3. Review upstream data/model licensing and include required notices.
4. Ensure no secrets, private paths, or unauthorized dataset copies are included.
5. Record the decision and scope of the license in the README.

Until then, please seek explicit permission for uses not otherwise authorized by law.
