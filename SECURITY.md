# Security Policy

## Reporting vulnerabilities

Please **do not disclose exploitable vulnerabilities, credentials, or private data in public GitHub issues**.

Contact the repository maintainers privately using GitHub's private vulnerability reporting feature **if enabled**, or another private contact method provided by the repository owner. No dedicated security email address is currently published.

## Scope

This is a research repository, not a production inference service. Pay particular attention to notebook dependencies, remote dataset downloads, supply-chain risks, accidental secret exposure, and untrusted model artifacts.

## Supported versions

No stable supported release or security response-time commitment has been announced. Fixes and disclosures are handled on a best-effort basis.
